# Lösung: Das Experiment

## Aufgabe 1 – Vorhersage

Hier gibt es keine falsche Antwort: Eine Vorhersage ist eine Vermutung, die sich erst im
Experiment bewähren muss. Wichtig ist, dass sie so genau formuliert ist, dass man sie
überprüfen kann («bei doppeltem Abstand mehr als doppelt so lange»).

## Aufgabe 2 – Messen

Die Messwerte hängen vom Zimmer und vom Tag ab. Typisch ist: Je grösser der Abstand, desto
länger dauert es – aber die Werte streuen stark, und manche Plätze melden früher als erwartet.

## Aufgabe 3 – Schwachstellen

Mehrere Antworten sind richtig. Gesucht sind konkrete Punkte, zum Beispiel:

| Bereich | Schwachstelle |
|---|---|
| Messgerät | Die Nase ist kein Messgerät: Menschen riechen verschieden gut. |
| Messgerät | Wer weiss, dass Essig kommt, meint ihn früher zu riechen (Erwartung). |
| Messgerät | Man gewöhnt sich an einen Geruch und nimmt ihn schwächer wahr. |
| Störgrössen | Die Luft bewegt sich: Heizung, Fenster, Türe, Personen. |
| Störgrössen | Möbel und Personen stehen im Weg. |
| Genauigkeit | Die Abstände sind geschätzt oder ungenau gemessen. |
| Genauigkeit | Zwischen Riechen und Melden vergeht Zeit. |
| Wiederholung | Pro Platz misst nur eine Person, und nur einmal. |
| Wiederholung | Das ganze Experiment wurde nur einmal durchgeführt. |
| Dokumentation | Temperatur und Menge der Essigessenz sind nicht festgehalten. |

Eine eigene Antwort, die hier nicht steht, kann genauso richtig sein – entscheidend ist, dass
sie erklärt, wodurch das Ergebnis verfälscht werden könnte.

## Aufgabe 4 – Beobachtung oder Beleg?

1. anekdotische Evidenz – ein einzelner Bericht ohne festgehaltene Bedingungen
2. kontrolliertes Experiment – geplant, wiederholt, dokumentiert
3. anekdotische Evidenz – eine einzelne Wahrnehmung, auch wenn sie im Experiment gemacht wurde

**Aus unserem Experiment ein kontrolliertes machen:** mit Sensoren messen statt mit der Nase,
Luftzug ausschliessen, Abstände ausmessen, bei jedem Abstand mehrmals messen, Temperatur und
Menge notieren, das Experiment wiederholen.
